# PharmaGuideRx Project Status

## v0.1.0 — Research prototype

### Implemented
- Streamlit user interface
- Patient/label input
- Gene, drug, and phenotype selection
- Explainable rule matching
- Demonstration pharmacogenomics dataset
- Safety and scope disclaimer
- Evidence notes
- GitHub Actions Python syntax check
- Project documentation

### Not implemented
- Clinical-grade variant calling
- VCF/star-allele assignment
- Live guideline synchronization
- Authentication and authorization
- FHIR/EHR integration
- Production audit infrastructure
- Clinical validation
- Regulatory clearance

This repository should be treated as an educational/research software prototype.
