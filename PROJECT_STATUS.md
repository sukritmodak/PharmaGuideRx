# PharmaGuideRx Project Status

## v0.3.0 — Integrated visual research workspace

### New
- First-screen login / demo access
- Top workspace navigation with Demo and New Patient options
- New synthetic patient profile workflow
- PyMOL-inspired interactive 3D molecular viewer
- PyRx-inspired virtual screening workspace
- Interactive molecular animation with play controls

### Existing
- 29 gene-drug demonstration records
- 8 synthetic patient profiles
- Explainable pharmacogenomics rule engine
- GitHub Actions Python syntax validation

### Scope
The visual molecular and docking components are educational UI demonstrations. They do not run PyMOL, PyRx, AutoDock, or validated clinical workflows.

All patient profiles and demonstration screening values are synthetic.
