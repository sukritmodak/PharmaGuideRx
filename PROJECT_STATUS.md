# PharmaGuideRx Project Status

## v0.2.0 — Expanded research prototype

### Implemented
- Streamlit pharmacogenomics interface
- Custom patient label
- Synthetic sample patient profile loader
- 29 gene-drug demonstration records
- Multiple metabolizer and response phenotype examples
- Example diplotype/marker fields
- Explainable rule matching
- Expanded demonstration knowledge base
- Synthetic patient profile table
- Safety and scope disclaimer
- GitHub Actions Python syntax check
- Project documentation

### Dataset scope
The expanded dataset covers examples involving CYP2C19, CYP2D6, CYP2C9, VKORC1, CYP4F2, TPMT, NUDT15, DPYD, SLCO1B1, ABCG2, CYP3A5, CYP2B6, UGT1A1, HLA-B, HLA-A, G6PD, CFTR and NAT2.

### Not implemented
- Clinical-grade variant calling
- VCF/star-allele assignment from laboratory files
- Live guideline synchronization
- Authentication and authorization
- FHIR/EHR integration
- Production audit infrastructure
- Clinical validation
- Regulatory clearance

All patient profiles and dataset records are synthetic demonstration content.
